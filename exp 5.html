Demonstrating GET and POST Methods Using HTML Forms

GET Method Form

The GET method sends the entered data through the URL. After submitting, observe the browser's address bar.



Example URL:

form_method_demo.html?student_name=Gayathri&department=IT

POST Method Form

The POST method sends the entered data inside the request body. The information will not appear in the browser URL.



Observation: Data is not visible in the URL after submitting.

GET vs POST Comparison

Feature GET POST
Purpose Retrieve Data Submit Data
Data Visibility Visible in URL Not Visible in URL
Security Less Secure More Secure
Common Usage Search Forms Login & Registration
